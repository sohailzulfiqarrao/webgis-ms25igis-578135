How this site is organised

One repository for the whole course, one folder per lab.

  • A folder for every lab Each lab keeps its own page, data and report, so later labs never overwrite earlier ones.
  • Static and public Plain HTML, CSS and JavaScript with Leaflet, served by GitHub Pages with no build step.
  • Reports on GitHub Each report holds the checkpoints, measurements and answers for its lab.
